# 04 — Arrays and Strings

Arrays store same-type values contiguously. A C string is an array of characters ending in \`\\0\`; it does not carry its own length.

## Examples

- \`examples/array_stats.c\` — min, max, and mean
- \`examples/string_palindrome.c\` — bounded input and two-ended comparison

## Practice prompts

1. Rotate an array left by one position.
2. Multiply two 3×3 matrices.
3. Count vowels, digits, and whitespace in a line read with \`fgets\`.
