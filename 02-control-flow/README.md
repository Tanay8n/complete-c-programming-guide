# 02 — Control Flow

Conditions and loops let a program make decisions and repeat reliable work.

## Examples

- \`examples/grade_calculator.c\` — \`if\`/\`else if\` ranges with validation
- \`examples/prime_numbers.c\` — loop and divisor test
- \`examples/leap_year.c\` — compound Boolean expression

## Practice prompts

- Print a multiplication table from 1 to 10.
- Read a positive integer and print its digits in reverse order.
- Draw a right-aligned triangle using nested loops.
