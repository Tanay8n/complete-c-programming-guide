# 10 — Lab Programs

These programs are deliberately short enough to type during a practical session. Each file is standalone and can be compiled with the same C11 command.

| File | Skill |
| --- | --- |
| \`01_sum_n.c\` | loop and arithmetic |
| \`02_fibonacci.c\` | iteration and state |
| \`03_gcd.c\` | Euclid's algorithm |
| \`04_matrix_transpose.c\` | two-dimensional arrays |
| \`05_string_length.c\` | character traversal |
| \`06_sort_numbers.c\` | selection sort |
| \`07_student_average.c\` | structures and functions |
| \`08_file_word_count.c\` | file I/O and state |
| \`09_stack_menu.c\` | menu-driven stack |
| \`10_linked_list_search.c\` | dynamic nodes |

Try each program first from its problem statement, then compare your implementation with the reference.
