# Question Bank

## Short-answer questions

1. **What is a compiler?** A program that translates source code into object code/executable code and reports translation errors.
2. **Why is \`main\` declared \`int\`?** It returns a status code to the host environment; zero conventionally means success.
3. **What is a dangling pointer?** A pointer that refers to storage whose lifetime has ended, such as freed memory.
4. **Why does binary search need sorted data?** It discards half the search interval based on ordering; without ordering that decision is not valid.
5. **What is recursion's base case?** The condition that stops further self-calls.

## Programming questions

- Reverse an integer without converting it to a string.
- Find the second-largest distinct element in an array.
- Count words in a line using whitespace transitions.
- Implement a queue using an array and two indexes.
- Merge two sorted arrays into a third array.
