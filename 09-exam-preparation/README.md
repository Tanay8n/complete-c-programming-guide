Use this section for revision after completing the modules. In a written answer, show the idea, a small trace, and the complexity when an algorithm is involved.

## Last-day checklist

- Trace a loop on paper and identify its termination condition.
- Distinguish \`=\` from \`==\`, and \`&x\` from \`*p\`.
- Explain array bounds and the string terminator.
- Draw a linked-list node and show how a pointer changes after insertion.
- Write at least one test case for zero, one, a negative value, and a boundary.
