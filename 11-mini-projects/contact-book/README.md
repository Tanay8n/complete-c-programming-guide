# Contact Book

This small project stores contacts in memory and saves them as a tab-separated text file when the program exits.

\`\`\`text
gcc -std=c11 -Wall -Wextra -pedantic main.c -o contact_book
\`\`\`

Run it, add a few contacts, list them, and search by name. The file \`contacts.tsv\` is created beside the executable.
