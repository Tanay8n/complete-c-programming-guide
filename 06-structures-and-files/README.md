# 06 — Structures and Files

Structures group related fields. Files make data survive after the program exits.

## Examples

- \`examples/student_records.c\` — array of structures and formatted output
- \`examples/file_copy.c\` — binary-safe byte copying with error checks

## Practice prompts

- Store five books and print the most expensive one.
- Write a CSV file of marks, then read it back and calculate the mean.
- Add a search-by-roll-number function to \`student_records.c\`.
