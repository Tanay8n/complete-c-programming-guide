# 12-Week Study Plan

| Week | Focus | Practice target |
| --- | --- | --- |
| 1 | Syntax, types, I/O | 01 fundamentals examples |
| 2 | Operators and conditions | Grade calculator and leap year |
| 3 | Loops and number problems | Prime, factorial, Fibonacci |
| 4 | Functions and recursion | GCD and recursive factorial |
| 5 | Arrays and matrices | Array statistics and transpose |
| 6 | Strings | Length, reverse, palindrome |
| 7 | Pointers | Swap, pointer traversal |
| 8 | Dynamic memory | Resizable integer list |
| 9 | Structures and files | Student records and file copy |
| 10 | Stacks and linked lists | Data-structure examples |
| 11 | Searching and sorting | Compare linear/binary search |
| 12 | Revision and projects | Lab set plus one mini project |

For every session, write one sentence answering: “What is the invariant or rule that makes this program correct?”
