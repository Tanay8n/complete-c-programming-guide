# 07 — Data Structures

Implementing a structure yourself makes the memory model visible. These examples use a fixed-capacity stack and a heap-allocated singly linked list.

## Examples

- \`examples/stack.c\` — push, pop, peek, and underflow handling
- \`examples/linked_list.c\` — append, print, and destroy

When choosing a data structure, state the operations you need and their expected complexity before writing code.
