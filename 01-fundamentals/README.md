# 01 — Fundamentals

Start here. Learn how a C program is translated, how variables store values, and how formatted input/output works.

## Learning goals

- Recognise headers, \`main\`, statements, and return values.
- Choose an appropriate integer, floating-point, or character type.
- Use arithmetic, relational, and logical operators.
- Validate simple input before using it.

## Examples

- \`examples/hello_world.c\` — smallest complete program
- \`examples/data_types.c\` — sizes and format specifiers
- \`examples/input_output.c\` — validated temperature conversion

## Exercises

1. Convert kilometres to miles and print two decimal places.
2. Read three integers and print their minimum and maximum.
3. Explain why integer division of \`5 / 2\` is \`2\`, then show how to obtain \`2.5\`.
